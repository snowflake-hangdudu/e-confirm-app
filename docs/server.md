## 登录方式

### 网页终端（控制台）

1. 协作者登录腾讯云 → 右上角切换到客户主账号  
2. 轻量应用服务器 → 点实例 → **登录**  
3. 选 **免密连接 (TAT)**，用户名 `ubuntu` → 登录  

### SSH（本机）

```bash
ssh ubuntu@124.222.62.190
```

密码见 `docs/server.secrets.local.md`。

控制台也可 **重置密码**；网页终端内可用 `sudo passwd ubuntu`。
